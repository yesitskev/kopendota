OpenDotaTimeouts

data class OpenDotaTimeouts(val connect: Duration = 10.seconds, val read: Duration = 30.seconds, val write: Duration = 10.seconds, val call: Duration = Duration.ZERO)(source)

Timeouts applied to the OkHttp client OpenDotaClient builds.

Each timeout is rounded down to whole milliseconds, and Duration.ZERO disables one. The defaults are generous enough for the slower OpenDota endpoints — the explorer and constants endpoints in particular — while still failing a request that will never arrive.
