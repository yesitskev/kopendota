OpenDotaLogLevel

enum OpenDotaLogLevel : Enum<OpenDotaLogLevel> (source)

How much detail OpenDotaClient writes to the HTTP log.

The levels mirror the ones OkHttp's logging interceptor offers, so logging can be configured without OkHttp on the compile classpath.
