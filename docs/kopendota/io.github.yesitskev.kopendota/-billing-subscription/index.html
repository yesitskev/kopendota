BillingSubscription

class BillingSubscription(val apiKey: String? = null, val cache: BillingSubscriptionCache = InMemoryBillingSubscriptionCache(), val freeTierLimits: BillingLimits = BillingLimits.FREE_TIER, val subscriptionTierLimits: BillingLimits = BillingLimits.SUBSCRIPTION_TIER, clock: Clock = Clock.systemUTC())(source)

The counts and limits of one OpenDota subscription, and the key its subscription-tier requests travel with.

Every request a client makes is counted twice: once against the UTC day, and once against the second it was made in, so that the sliding minute can be summed from the last sixty seconds. Both counts live in cache, which is why one subscription can be shared across processes.

// Free allowance first, then the subscription, counted within this process.
val subscription = BillingSubscription(apiKey = System.getenv("OPEN_DOTA_API_KEY"))

// The same, with the counts shared by every process that reaches the same Redis.
val shared = BillingSubscription(apiKey = key, cache = RedisBillingSubscriptionCache(redis))

// Never use the free allowance: send every request on the subscription.
val always = BillingSubscription(apiKey = key, freeTierLimits = BillingLimits(perDay = 0, perMinute = 0))
