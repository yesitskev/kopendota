OpenDotaClient

class OpenDotaClient(billingSubscription: BillingSubscription = BillingSubscription(), queueLimit: Int = 0, requestStrategy: RequestStrategy = FreeTierFirstRequestStrategy, json: Json = DEFAULT_JSON, logging: OpenDotaLogging = OpenDotaLogging(), timeouts: OpenDotaTimeouts = OpenDotaTimeouts(), baseUrl: String = BASE_URL) : AutoCloseable(source)

Assembles a ready-to-use OpenDota service, owning the Retrofit, OkHttp, JSON and rate limiting wiring that goes with it.

val client = OpenDotaClient(
    billingSubscription = BillingSubscription(apiKey = System.getenv("OPEN_DOTA_API_KEY")),
)

val match = client.openDota.getMatch(matchId = 7108753629L)
val wins = client.openDota.getPlayerWinLoss(accountId = 88367253L, heroId = 1L)

println(client.statistics().freeTierDay.remaining)

A client owns an OkHttp connection pool, the threads that serve it, and the coroutine scope queued requests wait on, so build one and share it rather than creating one per call. close releases all three.

Every call is held to what billingSubscription allows. By default that is the free allowance alone: calls go out anonymously, up to 3,000 a day and 60 in any sliding minute. Give the subscription an API key and calls spend the free allowance first, then carry the key once the free limits are reached. The key is redacted from the HTTP log at every OpenDotaLogLevel.

Parameters

billingSubscription

Allowances every call is counted against, and the key subscription-tier calls carry. The free allowance alone by default, with the counts kept in this process.

queueLimit

How many calls may wait for a rate limit at once, beyond which a call raises OpenDotaQueueLimitExceeded. 0, the default, is unlimited.

requestStrategy

Which tier each call goes out on. Free allowance first by default.

json

Serialiser the responses are deserialised with. Defaults to DEFAULT_JSON.

logging

How much of each request and response is logged, and where. Logs nothing by default.

timeouts

Timeouts applied to the underlying OkHttp client.

baseUrl

Base URL every endpoint path is resolved against. Must end with /, as Retrofit requires.
