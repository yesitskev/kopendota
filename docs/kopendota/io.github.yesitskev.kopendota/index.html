kopendota/io.github.yesitskev.kopendota

Package-level declarations

OpenDotaClient, which builds a ready-to-use service, and the OpenDota service definition it builds, covering every endpoint of the OpenDota API. OpenDotaLogging and OpenDotaTimeouts configure the client, and the error types a client will raise live here too — of which OpenDotaQueueLimitExceeded is the one anything throws so far.

Rate limiting lives here as well. A BillingSubscription holds the API key, the BillingLimits of each BillingTier, and the BillingSubscriptionCache its request counts are kept in — InMemoryBillingSubscriptionCache unless you put a shared store behind the interface. A RateLimiter holds every call to those limits, reading the BillingTierCapacity of each tier and asking a RequestStrategy which to send on; FreeTierFirstRequestStrategy spends the free allowance before the subscription. OpenDotaClient.statistics reports the result as OpenDotaStatistics, a count of what is queued and in flight alongside the OpenDotaUsage each tier has spent of its day and its sliding minute.
