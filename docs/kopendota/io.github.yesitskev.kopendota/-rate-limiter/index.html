RateLimiter

class RateLimiter(val subscription: BillingSubscription, val queueLimit: Int = 0, val strategy: RequestStrategy = FreeTierFirstRequestStrategy) : AutoCloseable(source)

Holds requests to what a BillingSubscription allows, picking the tier each one goes out on.

A request is admitted as soon as RequestStrategy finds a tier with room. Where neither tier has room the request waits, and queueLimit bounds how many may wait at once. The limiter counts the requests it has admitted but not yet billed as spent, so a burst of callers cannot all read an empty allowance and overshoot it together.

Only a billed response moves a count: an HTTP 404, 429 or 500 is not billed, which matches what OpenDota charges for. An HTTP 429 says a limit has been reached whatever the counts say, so the tier that answered it backs off for the Retry-After it gave, or for a minute where it gave none.

A client builds one of these, and OpenDotaClient.rateLimiter reaches it. Close the client to shut down the scope queued requests run on.
