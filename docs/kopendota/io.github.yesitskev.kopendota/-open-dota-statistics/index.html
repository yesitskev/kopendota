OpenDotaStatistics

data class OpenDotaStatistics(val queuedRequests: Int, val inFlightRequests: Int, val freeTierDay: OpenDotaUsage, val freeTierMinute: OpenDotaUsage, val subscriptionTierDay: OpenDotaUsage, val subscriptionTierMinute: OpenDotaUsage)(source)

A snapshot of what a client is doing and what it has spent.

Read it with OpenDotaClient.statistics. The counts are read one after another rather than under a single lock, so a snapshot taken while calls are in flight describes a moment that is already passing — it is for reporting on a client, not for deciding whether the next call will be admitted.

val statistics = client.statistics()

println("${statistics.inFlightRequests} in flight, ${statistics.queuedRequests} waiting")
println("free day: ${statistics.freeTierDay.used}/${statistics.freeTierDay.limit}")
println("free minute: ${statistics.freeTierMinute.remaining} left of the sliding minute")
