OpenDotaLogging

data class OpenDotaLogging(val level: OpenDotaLogLevel = OpenDotaLogLevel.NONE, val logger: (message: String) -> Unit = DEFAULT_LOGGER)(source)

HTTP logging configuration for OpenDotaClient.

Nothing is logged by default. The API key is never logged: OpenDotaClient redacts the api_key query parameter before a line reaches logger, whatever the level.
