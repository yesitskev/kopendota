kopendota/io.github.yesitskev.kopendota.model

Package-level declarations

Response models for the OpenDota API.

Each endpoint has a top-level model named after it — MatchResponse for GET /matches/{match_id}, PlayerWinLossResponse for GET /players/{account_id}/wl, and so on. Models shared by several endpoints are named …ObjectResponse, such as MatchObjectResponse and PlayerObjectResponse.

Nested JSON objects become their own class, named by appending the field path to the owning model: MatchResponse.players holds MatchResponsePlayers, whose purchase_log field holds MatchResponsePlayersPurchaseLog. Names map to JSON keys through @SerialName, so a property is camel-cased where the API uses snake_case.
