MatchResponseObjectives

@Serializable
data class MatchResponseObjectives(val time: Long? = null, val type: String? = null, val unit: String? = null, val key: String? = null, val slot: Long? = null, val playerSlot: Long? = null, val team: Long? = null, val value: Long? = null, val killer: Long? = null, val victimPlayerSlot: Long? = null)(source)

Objective events such as tower, barracks and Roshan kills.

Which members carry a value depends on type: a building_kill names the building in key and its killer in unit, while a CHAT_MESSAGE_ROSHAN_KILL carries only team.
